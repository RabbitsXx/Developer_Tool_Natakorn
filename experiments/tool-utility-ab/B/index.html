Developer Tool Natakorn ดูโปรเจกต์บน GitHub ↗

เครื่องมือสำหรับ AI coding agent

ให้ AI เข้าใจโปรเจกต์ ก่อนเริ่มลงมือ

ชุดคำสั่ง CLI ที่ช่วยเตรียมคำแนะนำและ skills ให้ agent พร้อมตรวจบริบทโปรเจกต์และทำงานต่อจาก session ก่อนหน้า

เริ่มต้นจาก GitHub
เริ่มจาก CLI
$ node bin/natakorn.mjs doctor
$ node bin/natakorn.mjs init --target <project> --agent all --dry-run

เริ่มงานพร้อมบริบท

ตรวจ stack และ lockfile ของโปรเจกต์ แล้วเตรียมคำแนะนำกับ skills ให้ agent

กลับมาทำต่อได้

บันทึกสถานะโปรเจกต์ไว้สำหรับ session ถัดไป

ตรวจแผนก่อนติดตั้ง

ใช้โหมด dry-run ดูรายการที่จะเปลี่ยนก่อนเริ่มติดตั้งจริง

เริ่มใช้งาน

Clone โปรเจกต์ ตรวจเครื่องมือ แล้วเตรียมแผนติดตั้งกับโปรเจกต์ของคุณ

$ git clone https://github.com/RabbitsXx/Developer_Tool_Natakorn.git
$ cd Developer_Tool_Natakorn
$ node bin/natakorn.mjs doctor
$ node bin/natakorn.mjs init --target <project> --agent all --dry-run

ตรวจแผนแล้วค่อยรันคำสั่ง init อีกครั้งโดยเอา --dry-run ออก
