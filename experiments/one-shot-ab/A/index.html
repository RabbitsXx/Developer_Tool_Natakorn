Less guessing, clear steps

A steadier way into any codebase.

Start from the repository you have. Add guidance where it is missing, then keep an eye on what changes.

01 / INSPECT

See the project clearly

Detect the stack, profiles, and useful capabilities before deciding what the repo needs.

02 / INIT

Add only what is missing

Install agent instructions and skills with a dry run to preview changes before applying them.

03 / VERIFY

Keep changes reviewable

Check tracked files for edits or drift, and run the repository's verification workflow.
