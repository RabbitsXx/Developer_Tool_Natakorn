ให้ AI รู้จักโปรเจกต์ ก่อนเริ่มลงมือ

ชุดเครื่องมือสำหรับ AI coding agent ที่ช่วยตรวจ stack และ lockfile เพิ่มคำแนะนำกับ skills และเก็บสถานะโปรเจกต์สำหรับ session ถัดไป

ดูโปรเจกต์บน GitHub
project-context
01project = existing
02stack = detected
03instructions = ready
04agent → start with context

เริ่มจากโปรเจกต์ที่มีอยู่

ดูบริบท วางแผนก่อนเปลี่ยน แล้วค่อยเริ่มงานกับ agent

  1. 01

    ตรวจบริบท

    อ่าน stack, profiles และสถานะการเปลี่ยนแปลงของโปรเจกต์ โดยไม่เขียนไฟล์

  2. 02

    ดูแผนก่อนติดตั้ง

    ตรวจรายการที่จะเพิ่มได้ด้วยโหมด dry-run ก่อนนำไปใช้กับโปรเจกต์

  3. 03

    เปิดงานใน agent

    หลังติดตั้งคำแนะนำแล้ว เปิดโปรเจกต์ใน agent และเริ่มจาก START_PROMPT.md

เริ่มต้นได้จาก CLI

ตรวจเครื่องมือในเครื่อง แล้วดูแผนติดตั้งสำหรับโปรเจกต์ของคุณก่อน

รันจากโฟลเดอร์ Developer Tool Natakorn

$ node bin/natakorn.mjs doctor
$ node bin/natakorn.mjs init --target <project> --agent all --dry-run

เมื่อพร้อมติดตั้ง ให้รันคำสั่ง init อีกครั้งโดยเอา --dry-run ออก
