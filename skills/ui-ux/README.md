# UI/UX Skill Pack

Version: 1

Use this pack only for user-facing UI/UX work. Do not load every skill for a trivial styling change.

## Activation

- New page / product flow / redesign: read 01, 02, 03, 04, 05.
- Existing page UX fix: read 01, 03, 04, 05.
- Design-system/component work: read 02, 03, 05.
- Mobile/responsive bug: read 04 and 05.
- Small visual fix: read 03 and 05 only.

## Core principle

Complex backend, simple frontend. Design for the actual user, not for the developer who understands the architecture.

A user should quickly understand:
1. Where am I?
2. What matters here?
3. What should I do next?
4. What will happen when I act?

## Required workflow for substantial UI work

Requirement → user goal → task flow → information architecture → wireframe/hierarchy → design system → implementation → responsive verification → browser/visual/accessibility QA.

Do not call a UI complete because it compiles. Browser behavior and visual quality require separate evidence.
