# RTK command convention

RTK (Rust Token Killer) reduces noisy terminal output for AI-assisted development.

When `rtk` is installed, prefix shell commands with it:

```text
rtk git status
rtk npm install
rtk npm run build
rtk pytest -q
```

Useful checks:

```text
rtk --version
rtk gain
```

This repository does not store a machine-specific executable or secret. On a new machine, install RTK using the official instructions, then enable the AI/CLI integration. If the command is not available, continue with the normal command and mention the fallback.
